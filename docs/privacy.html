Privacy policy

Last updated: 4 November 2026

Cogwise Studio is a private tool used only by the owner of the Cogwise channel (contact: cogwisehtw@gmail.com) to manage his own YouTube channel.

Data accessed

With the owner's authorization through Google OAuth, the tool uses the YouTube Data API to upload videos, read public statistics of the channel's videos, read comments posted on those videos and publish replies. It does not access any other Google data.

Use and storage

This data is used only to publish videos, show the owner his channel statistics and comments, and post the replies he approves. Authorization tokens are stored privately by the owner and are never shared. Public comment text and author names may be shown in the owner's private dashboard. No data is sold, shared with third parties or used for advertising.

Google API Services

Cogwise Studio's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube API Services are used under the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time from Google account permissions. On request to the contact address, any stored data is deleted.
